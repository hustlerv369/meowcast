Good questions.

Is Meowcast free?

The local core is free, including Notes, Whiteboard, and the offline Prompt Master. Optional AI uses your own supported subscription or API account. Provider limits and API charges still apply.

Can I use it on my Mac?

macOS version coming soon. Meowcast is available for Windows now; a Mac download is not available yet.

Which AI connections can I use?

Connect ChatGPT, Claude, Cursor or Antigravity through the available integrations, or configure a compatible API endpoint with your own key. Meowcast is open source, so you can modify the integrations and add support for other providers. Availability depends on your provider account and the integration you configure.

Does my work stay on my computer?

Notes and Whiteboard are local. Clipboard history is off until you enable it; persistence is optional and encrypted. Text you explicitly send to an AI provider leaves your computer and follows that provider's policies. Meowmate has its own storage and connections. Cloud sync is not included.

Can I make it feel like mine?

Choose Light, Dark, or System on first launch. Adjust appearance, keyboard shortcuts, enabled extensions, clipboard capacity, and AI connections in settings.

Does Meowmate generate images automatically?

It can help prepare an image prompt, copy it, and open Gemini in your browser. You generate and download the image there using your own account. Automatic image generation inside the dock is not included.
