# Start using Meowcast

Launch Meowcast and choose Light, Dark or System in the welcome guide. Press Alt + Space to open the launcher. You can change its shortcut in Settings → General.

Search for an application or tool and press Enter to open it. Click the star beside a result to keep it as a favorite. With an empty search, favorites appear first, followed by frequently used entries. Typed searches keep their normal search relevance.

Open Settings from the launcher's Actions button. Appearance controls the launcher theme; Extensions controls which tools appear. Clipboard history is opt-in. Its capacity and persistence are separate preferences.

Meowmate starts alongside Meowcast by default. The cat dock opens its panel. You can disable this startup behavior in Meowcast's General settings. The companion has its own settings and conversation history.

## Your AI account

Use the official Codex client to sign in with your own account. In Meowmate Chat, select an available model before sending. Changing the model after a conversation starts asks you to begin a new chat. In Tasks, the model applies to that individual task. A task can edit files and run commands in the chosen project; choose the folder deliberately.

Meowcast's Text studio has separate AI connection settings, including supported API providers. Test a connection before using it for your work. Subscription access, model availability and usage limits are controlled by the provider. API usage may have a separate bill.

## Images

Write an idea, choose a style and framing, then use Improve prompt. The offline Prompt Master structures the text; it does not contact an AI service. You can edit it or restore the original idea.

A reference thumbnail stays local. Copy the prompt, open Gemini, paste it and attach the reference there. This preview does not submit a generation automatically or transfer your browser login.
